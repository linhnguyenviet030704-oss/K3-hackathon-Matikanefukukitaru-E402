# File Reflection

Tạo một file cho mỗi thành viên trước khi nộp:

```text
reflection/<mã-học-viên-hoặc-tên>.md
```

Mẫu:

```markdown
# Reflection - [Tên]

## Vai trò
[Phần mình phụ trách]

## Đóng góp của mình
[File/tính năng/artifact cụ thể]

## AI đã hỗ trợ thế nào
[AI tạo phần nào, mình rà gì, mình sửa gì]

## Một bài học từ case chưa đạt
[Nêu một lỗi đánh giá/validation và thay đổi sau đó]
```
